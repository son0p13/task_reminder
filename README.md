# Task Reminder

Ứng dụng quản lý công việc và nhắc nhở thời hạn viết bằng Python và giao diện đồ họa Tkinter.

## Tính năng chính
- Thêm, sửa, xóa công việc cần làm
- Đánh dấu trạng thái Hoàn thành / Chưa xong
- Hỗ trợ chọn Deadline từ bảng lịch trực quan hoặc nhập trực tiếp
- Sắp xếp tăng/giảm dần theo từng cột (ID, Tên, Mức ưu tiên, Deadline, Trạng thái)
- Lọc theo trạng thái và tìm kiếm nhanh theo từ khóa
- Tự động lưu trữ dữ liệu vào file JSON

## Hướng dẫn cài đặt và sử dụng
Chỉ cần cài đặt Python (phiên bản 3.8 trở lên). Ứng dụng sử dụng toàn bộ thư viện chuẩn của Python, không cần cài thêm thư viện ngoài.

Khởi chạy ứng dụng:
```bash
python main.py
```
